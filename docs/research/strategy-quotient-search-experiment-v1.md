# 目标策略商搜索对照实验 v1

## 实验问题

在同一有限随机对抗博弈上，比较三种执行方式：

1. 从合法开局纯 strict 正向展开；
2. 从终局公式纯符号反向生成；
3. 反向过近似包络、目标策略商证明、独立正向补集挑战的混合方法。

实验不比较“最快找到一条路线”，而比较全部潜在有效策略类的召回、错误硬剪枝、未决债务和后续昂贵 strict 路线根数量。符号关系比较和 strict 路线展开分开计量。

## 固定测试域

测试域有 `66` 个候选单元，其中 `58` 个可从声明开局到达，精确规则行为商为 `11` 类，精确 Pareto/交替支配意义下潜在有效类为 `6` 类。域内特意包含：

- `24` 个坐标不同但未来规则行为相同的副本；
- `24` 个确定劣化绕路；
- 对手多一个有害回应的状态；
- 期望值相同但分布不同的 Chance 状态；
- `8` 个终局看似理想但从开局不可达的反向诱饵；
- 一个反向生成器未知、但实际更优的隐藏规则链；
- 一个可由乐观上界对保证下界证明删除的候选。

完整穷举只作为本有限测试域的 oracle，不进入生产算法。

## 结果

| 方法 | 是否完整 | 昂贵 strict 根 | 有效类召回 | 未决/错误硬剪枝 |
| --- | ---: | ---: | ---: | ---: |
| 纯正向完整展开 | 是 | `58` | `6/6` | `0/0` |
| 纯反向完整处理已发现项 | 否 | `65` | `5/6` | `1/0` |
| 混合策略商 | 是 | `9` | `6/6` | `0/0` |

混合方法先保留 `8` 个代表，并把反向遗漏的 `hidden-superior` 自动列入一个正向补集挑战；补集命中后重新封账。最终 `58` 个单元取得不可达、交替支配或上下界证书，昂贵 strict 根相对完整纯正向减少 `84.48%`。代价是两次商固定点在当前小夹具上为亚秒级但波动明显，保守上界为 `20,736` 次符号状态对检查；墙钟数字只作诊断，不作为性能承诺。

在与混合方法相同的 `9` 个 strict 根预算下，对纯正向和纯反向各做 `128` 个确定性随机排列：

- 纯正向平均召回 `13.67%`，最高 `50%`，没有一次达到 `100%`；
- 纯反向平均召回 `9.24%`，最高 `33.33%`，没有一次达到 `100%`；
- 混合方法保持 `100%`，因为剩余项不是按排序丢弃，而是必须获得证书或进入补集队列。

安全负例全部通过：`24` 个坐标副本合并；均值相同但 Chance 分布不同的两项不合并；对手新增有害回应的两项不合并；反向遗漏不被解释为不可达。

## 实验暴露的设计修正

首轮实验曾把“不可达反向诱饵”和“可达隐藏优解”赋予同一个比较签名。由于两者未来行为相同，双模拟正确地把它们归为一类，但不可达代表不能替代声明初始分布中的可达策略，导致召回统计被虚假补齐。

因此 `Q_goal` 的比较键必须包含声明初始分布、历史/观察签名和可达上下文。未来行为等价只允许合并规则行为，不自动授权一个不可达成员代表可达策略。该负例已固定进实验夹具。

## 结论与边界

实验支持继续采用混合方案：它在该有限域上同时得到完整召回、零错误硬剪枝和显著少于纯正向的 strict 根，也能发现纯反向漏掉的优解。它否定了两种简化：只跑反向不能声称完整；在相同小预算下直接正向抽样也不能声称保留全部有效策略。

本实验还不能证明真实 Warmachine 连续 `Q_rule` 已经有限和完整，也不能证明混合方法在所有域都比纯正向更快。真实接入仍必须完成 Ticket 20 的 Host 谓词闭包、转移稳定和历史签名，并在刺杀、得分两种真实任务上重复同分母对照。

执行命令：`npm run experiment:strategy-quotient-search`。
