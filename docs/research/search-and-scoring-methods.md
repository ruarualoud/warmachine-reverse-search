# 终局反推、对抗搜索与多维评分研究

## 状态

- 研究日期：2026-08-10
- 结论状态：足以确定下一阶段原型架构；具体评分权重仍需用微型题和固定基准校准。
- 产品声明：输出“最佳已发现候选”，不证明被效率门槛或预算排除的路线中不存在更优策略。

## 结论摘要

本项目不应被描述为“无数据 MuZero”。MuZero 需要从轨迹中学习隐式动力学、奖励、策略和价值，再在学习模型上运行 MCTS；我们已经拥有 rules-v1 精确模拟器，更合理的顺序是先用终局反推和 strict 搜索生成冷启动轨迹，之后再训练 MuZero 类模型。[MuZero 原论文](https://arxiv.org/abs/1911.08265)明确把奖励、策略和价值作为训练目标，并区分了完美模拟器搜索与学习模型搜索。

推荐架构不是纯逆向状态求逆，而是：

1. 从最小胜利证明生成目标约束。
2. 用回归规划和类型化前驱算子向合法开局扩展。
3. 用 OR/AND/Chance 图分别表达我方选择、对手反制和随机结果。
4. 用多目标 Pareto 账本保留候选，不提前压成单一策略分数。
5. 用 rules-v1 strict 正向重放认证每条输出路线。
6. 通过受控实验决定是否用正向 MCTS 连接反向里程碑。

## 理论映射

### 目标回归

STRIPS 将目标条件通过动作的前提与效果向前驱状态回归，是“从终局义务反推需要什么”的直接理论来源。[Fikes 与 Nilsson 的原始 STRIPS 论文](https://ai.stanford.edu/~nilsson/OnlinePubs-Nils/PublishedPapers/strips.pdf)支持符号目标回归，但经典模型假定离散、确定且动作模型已知；Warmachine 的对手选择、触发顺序和骰子不能被压成普通确定动作。

因此本项目的反向节点应是“前驱义务”，而不是声称已经求得唯一逆状态。一个伤害终局可以回归成命中、伤害、射程、LOS、资源和存活等义务；满足这些义务的攻击者、规则和位置可能有很多组。

### 从目标附近逐层扩展

[Reverse Curriculum Generation](https://arxiv.org/abs/1707.05300)从已知目标状态附近采样起点，再逐渐向更远起点扩展；[Backplay](https://arxiv.org/abs/1807.06919)沿示范轨迹从终点向起点移动训练起始位置。两者证明“先解决目标附近，再扩大开局盆地”可改善稀疏奖励问题，但都不证明枚举了所有可达前驱。

对本项目的用途是：

- 按胜利事件、激活、回合、上一回合和上一轮迭代加深。
- 把已经 strict 认证的路线作为后续训练或前驱提议的课程。
- 不把“当前课程没生成”解释成“不可能”。

### 双向搜索与正向补全

[Front-to-Front Heuristic Search for Satisficing Classical Planning](https://www.ijcai.org/proceedings/2020/567)说明前后搜索真正相遇可以解决单向搜索未解决的实例；[Predicting the Effectiveness of Bidirectional Heuristic Search](https://ojs.aaai.org/index.php/ICAPS/article/view/6672)同时指出图的不对称性和关键状态决定双向搜索是否获益。Warmachine 高度不可逆，反向义务和正向完整状态并不天然同构，因此正向补全只能作为待验证假设。

原型必须比较：

- 纯反向生成原子路线后 strict 重放。
- 反向只生成里程碑，正向搜索连接。
- 反向生成大部分路线，仅在未解析间隙启动正向连接。

不得因为双向搜索在其他领域有效，就预设它在高分支 Warmachine 中有效。

### 对抗与随机分支

二人回合制搜索不能把对手回合当随机噪声。反向图至少包含：

- OR：当前策略控制方可选择任一路线。
- AND/对抗：路线必须评估对手的重要合法回复。
- Chance：命中、伤害、随机移动和场景随机效果按概率质量分开。

[Probability Based Proof Number Search](https://www.scitepress.org/PublishedPapers/2019/73868/pdf/index.html)展示了在 AND/OR 游戏树中结合证明/反证明难度与 Monte Carlo 估计的做法。它适合启发“优先展开最可能改变结论的分支”，但我们的主观剪枝使搜索不具备完整求解证明，不能沿用其 solved 标签。

### 多目标与门槛

[Multi-objective Monte-Carlo Tree Search](https://proceedings.mlr.press/v25/wang12b.html)使用超体积指标处理多维回报；[Threshold UCT](https://ojs.aaai.org/index.php/AAAI/article/view/34858)在成本约束 MCTS 中维护效用/成本 Pareto 曲线。这两类方法支持先保存多维候选，再按使用场景选择偏好，而不是一开始写死一个总分。

建议候选向量至少保存：

| 维度 | 含义 |
| --- | --- |
| `strictWitness` | 是否存在完整 strict 正向见证 |
| `terminalProbability` | 路线在已展开 Chance 分支中的成功概率 |
| `opponentRobustness` | 面对已展开对手回复的最坏、均值和覆盖率 |
| `turnDistance` | 距离胜利事件的回合/激活层数 |
| `resourceMargin` | 达成路线后剩余 Focus/Fury、动作、模型和关键能力 |
| `exchangeVector` | 双方模型分、位置、节奏和场景压力变化 |
| `spatialSlack` | 射程、LOS、移动、控制区和站位的容错 |
| `routeRedundancy` | 同一开局可到达同终局的独立候选数量 |
| `unresolvedMass` | 未展开对手、随机、阵型、单位历史和规则来源 |
| `proposalCost` | strict 调用、节点、时间和内存成本 |

## 剪枝规则

### 可作为结构性硬过滤

- rules-v1 明确拒绝的动作或状态。
- 能力瓶颈证明某个模型、武器或规则不能满足义务。
- 最乐观移动、射程、伤害、资源或时间上界仍无法满足终局。
- 完整规则状态和未来能力都相同，且一个候选在全部保留维度上被另一个候选支配。
- 用户声明的概率/效率下界；但这只定义提议宇宙，不能证明被删路线无效。

### 只应排序或延迟展开

- 当前回合材料损失。
- 暂时让出场景分数或位置。
- 路线较长。
- 需要主动兑换。
- 与人工战术先验不一致。
- 当前 LLM/Skill 评分较低。

这些特征可能属于有效长线策略，不得单独作为“不可能”的依据。

## 两种搜索模式

### 当回合模式

- 输入完整当前状态和剩余激活。
- 终局距离限制为当前回合。
- 尽量枚举全部相关合法动作、对手反应与骰子质量。
- 适合精确刺杀计算、当前回合得分和能力瓶颈验证。

### 长线模式

- 使用胜利相对时间迭代加深。
- 允许部署、资源准备、主动兑换、场景压力和完整对手回合。
- 以义务、状态等价类和 Pareto 前沿控制规模。
- 预算截断与效率门槛均进入 `unresolvedMass` 或 proposal-denominator 记录。

## 有限原型矩阵

| 原型 | 目的 | 比较对象 | 通过条件 |
| --- | --- | --- | --- |
| 单动作刺杀 | 验证终局回归 | 穷举正向真值 | 所有保留候选 strict 可达，无错误演员 |
| 资源刺杀链 | 验证能力瓶颈 | 全动作枚举 | 锁定正确重机/施法者/资源来源 |
| 单次 Chance | 验证概率质量 | 精确骰子分布 | 概率总质量守恒 |
| 一次对手回合 | 验证 AND/回复 | 小型完整博弈树 | 未展开回复不被当成胜利 |
| 主动兑换 | 验证长线评分 | 当回合与长线模式 | 不因即时材料亏损错误剪枝 |
| 得分状态机 | 验证历史终局 | Steamroller 2026 真值 | 计分窗口和领先条件准确 |
| 反向/正向补全 | 决定混合架构 | 三种连接方案 | 以见证率、节点、strict 调用和质量选择 |
| Cryx/Fane 固定题 | 真实可用性 | 当前原型与新系统 | 双终局、完整部署、可恢复报告全部通过 |

## 对 MuZero 的接口

MuZero 训练数据应在 strict 认证后生成：状态观察、合法动作掩码、搜索访问分布、搜索价值、实际终局回报、规则/Host 凭据和提议边界。反向候选可以提供稀有胜利附近的冷启动样本，但未认证前驱、主观剪枝分数和 wildcard 规则不得标成环境真值。

## 推荐决定

1. 采用“终局义务回归 + OR/AND/Chance + Pareto 候选账 + strict 正向认证”。
2. 当回合模式先追求高覆盖精确搜索；长线模式接受最佳已发现候选口径。
3. 正向补全不进入既定架构，先通过专门原型决定。
4. 评分研究到此足以解锁完整状态和前驱代数设计；权重校准留给固定基准。
