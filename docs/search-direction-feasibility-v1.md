# Search Direction Feasibility V1

This contract measures forward and reverse expansion under one declared denominator and allocates the next bounded compute batch. It is a scheduler, not a reachability rule or tactical evaluator.

## Same denominator

Every comparison binds the same terminal family, horizon layer, Host receipt, search context, proposal universe and canonical state schema. Forward and reverse samples report the same counters:

- expanded nodes;
- generated, consistent, unique and unresolved candidates;
- strict transition calls and strict connection witnesses;
- elapsed time and peak bytes;
- coarse and strict join matches;
- optional constraint-variable contraction.

Derived measurements include effective unique fanout, consistency and merge rates, unresolved rate, strict-witness cost/yield, bytes per unique candidate and join false-positive rate.

## Calibration boundary

No numeric threshold is treated as theory. An active scheduling policy must bind at least one benchmark receipt and declare all thresholds with `thresholdRole=calibration_prior_not_theory`. Without that evidence the result is `collect_more_measurements`.

The gate can select `expand_reverse`, `expand_forward_connector`, `expand_bidirectional`, `alternate_measurement_batches`, `collect_more_measurements` or `freeze_and_defer`. It never removes a candidate or changes reachability disposition. Work not expanded because of memory, time or uncertainty remains unresolved.

## Intended use

Reverse expansion is favored near selective terminal certificates when it produces strict connections at lower measured cost. Forward connection is favored when reverse unknown mass or symbolic growth exceeds the calibrated envelope, or when exact movement, collision, activation, reaction or Chance execution is the remaining gap. Bidirectional expansion is allowed only when the measured costs are near a tie and observed strict join precision is within the calibrated limit.

Tactical annotations, material value, scenario preference, Skill advice and LLM scores are not consumed by this module. Downstream strategy analysis remains separate.
