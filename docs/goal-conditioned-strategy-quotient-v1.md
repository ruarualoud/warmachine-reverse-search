# 目标条件化策略有限商 v1

## 目的

本设计回答的不是“搜索能否结束”，而是：在完整 rules-v1 行为空间上，能否把大量策略上重复或确定无效的状态/动作合并或剪掉，同时保留任务声明下全部可能有效的策略类。

必须区分三层：

1. **规则行为商 `Q_rule`**：保留 Host 可观察合法动作、对手回应、Chance 分布和后继关系。Ticket 20 负责把连续几何与离散激活域变成有限且转移稳定的表示。它保证规则合法性不因离散化丢失，但通常仍然很大。
2. **目标策略商 `Q_goal`**：在相同规则、时域、信息和目标向量下，利用交替随机模拟、Pareto 支配和可证上下界合并或剪枝。Ticket 22 负责证明它不删掉任何可能有效的策略类。
3. **多回合求值**：Ticket 21 在 `Q_goal` 上闭合我方、对手和 Chance，计算精确值或守恒区间。

反向搜索的职责不是生成“已经找到的好路线”这个欠近似集合，而是从胜利公式构造**所有潜在有效策略的过近似包络**。正向搜索负责物化包络、寻找伪前像，并独立挑战包络外仍未证明可删的空间。

## 声明域

“全部有效策略”只有相对以下固定声明才有可检验含义：

- rules-v1 Host、卡牌数据、场景和地图收据；
- 双方完整军表、部署、先后手和公开信息模型；
- 有限回合/步数时域与终局规则；
- 目标向量及每个维度的单调方向；
- 允许的策略记忆、随机化和观察历史。

任一项变化都会使策略商收据失效。若要同时保留未来任意未知偏好，则不能做策略级 hard prune，只能使用 `Q_rule`。

## 目标向量

不能用一个 ranker 分数定义有效性。v1 保存多维结果和 Pareto 前沿，至少包括：

- 刺杀/场景终局及其概率；
- 逐结算窗得分和最终分差；
- Leader 生存与受到威胁的结果；
- 模型、军表分值和关键能力的存亡；
- Focus/Fury、尸体/灵魂、持续法术等资源状态；
- 区域控制、争夺和下一层合法威胁/脱离动作集合；
- 达成结果所需回合与激活成本；
- 未闭合对手回应和 Chance 质量。

某策略在至少一个单调偏好下可能成为 Pareto 非支配策略时，视为“潜在有效”。新增目标维度后必须重建旧商，不能把旧支配结论沿用到新目标。

## 交替随机支配

记 `p <= q` 表示在同一声明域内，`q` 对我方不劣于 `p`。候选关系只比较相同剩余时域、行动方、观察/历史签名和规则上下文的状态，并迭代到最大固定点。

- **终局**：`q` 的结果向量逐维不差于 `p`。
- **我方节点**：`p` 的每个动作都必须在 `q` 中存在一个动作，其即时结果不差，且后继分布可沿 `<=` 完整提升。
- **对手节点**：`q` 的每个对手动作都必须在 `p` 中存在对应动作并满足后继提升。量词反向，确保 `q` 没有给对手新增更有害的回应。
- **Chance 节点**：两边完整概率分布之间必须存在只沿 `<=` 配对的质量耦合；概率质量必须精确守恒。
- **规则与信息**：触发、持续状态、行动历史、可观察信息和未来动作资格不兼容时，关系立即失败。

实现合同把初始分布、历史、观察、可达前缀和剩余时域组合为每个状态的 `strategyContextKey`。该键缺失或不同的状态不能进入模拟/双模拟候选对；任一声明状态缺键都会使 `strategyContextComplete=false`，从而禁止完整性声明。

合并必须由同一个对称关系直接满足概率交替双模拟；“两个方向分别存在单向模拟”一般弱于双模拟，不能据此构造商。单向支配只允许把被支配项指向保留见证，不能抹掉原身份和证据。

## 反向过近似包络

`Q_rule` 中每个声明内单元必须进入唯一处置：

| 处置 | 允许条件 | 是否进入正向挑战 |
| --- | --- | --- |
| `retained` | 反向必要条件命中或当前 Pareto 前沿代表 | 正向 strict 物化 |
| `proven_unreachable` | 完整转移关系上的不可达证明 | 否，保留证明 |
| `dominance_pruned` | 有目标兼容的交替随机支配见证 | 否，保留代表映射 |
| `upper_bound_pruned` | 候选乐观上界被一个已认证策略的保证下界逐维支配 | 否，保留上下界证明 |
| `unresolved` | 其它所有情况，包括反向未命中、预算停止和证据不完整 | 是 |

不存在“没搜到所以删除”。所有未出现在反向包络中的 `Q_rule` 单元自动进入 `unresolved`，由独立正向补集队列探索。

## 正向挑战与精化

正向阶段有两个不同任务：

1. **包络物化**：从合法开局 strict 执行反向约束，发现伪前像后按 Host 差异谓词拆分抽象单元。
2. **补集挑战**：按乐观价值上界探索所有 `unresolved` 单元，而不是只在反向生成区域内搜索。发现比当前前沿更好的 strict 路线时，把新目标支持模式、历史或规则谓词加入反向语言并重建相关分区。

对已经有数学证书的 hard-pruned 单元只做抽样审计；若抽样产生反例，说明证书实现有错，必须使整批商失效，而不是把该路线当普通新发现。

## 完整性门

在有限时域内，只有同时满足下列条件才允许标记 `effectiveStrategyQuotientComplete=true`：

- `Q_rule` 有限、完整且转移稳定；
- 终局族、目标向量和信息/历史模型完整并绑定收据；
- 我方、对手与 Chance 后继全部闭合；
- 交替随机支配与对称概率交替双模拟分别达到固定点，所有概率提升精确守恒；
- 每个 `Q_rule` 单元都有唯一且验证通过的处置；
- `unresolved=0`，补集正向队列为空；
- 每个被支配策略都有保留代表和可重放见证；
- 每个上界剪枝都有候选乐观上界、保留策略保证下界和逐维支配证明；
- CEGAR 没有待处理的伪前像或反例。

在这些条件下，可以声明：每个具体 Pareto 非支配策略在商空间中都有一个结果不差的代表。不能据此声明未来规则、未知目标、无限时域或全部军表上的全局最优。

## 规模边界

该方案保证有限与可审计，不保证多项式规模。若很多策略在目标向量上真实互不支配，Pareto 前沿本身可能指数增长，它们必须保留。此时可使用预算和近似前沿提高速度，但输出必须降级为区间/近似，并保留未决质量，不能继续宣称完整策略商。

## Warmachine 接入顺序

1. Ticket 20 生成 `Q_rule`、动作/几何游标和转移稳定收据。
2. Ticket 22 为同一剩余时域计算目标兼容交替随机模拟、策略等价类和逐单元处置账。
3. Ticket 21 在保留商上递推值，并持续把未决补集送入 strict 正向挑战。
4. Ticket 09/10 只发布 Pareto 路线、值区间、策略代表映射、剪枝证书和未决空间；没有完整性收据时不发布“全部有效策略”结论。
