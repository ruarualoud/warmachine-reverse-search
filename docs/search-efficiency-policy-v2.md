# Warmachine 搜索效率策略 V2

> 架构说明：本策略属于认证路线的下游比较与实验分析，不属于反向可达性核心。反向核心不读取这里的交换、场景压力、材料或战术偏好，也不得据此拒绝或删去合法前驱。纯反向契约见 [reverse-reachability-boundary-v2.md](reverse-reachability-boundary-v2.md)。

## 结论

搜索不使用单一总分决定路线有效性。每条路线保存多维区间、证据完整度和来源，再用 Pareto 关系与稳定偏好元组排序。规则不可能、本次提议宇宙之外、预算未展开和策略偏好较低是四种不同状态，不能合并为“失败”。

## 效率向量

每个维度保存方向、上下界、完整性和证据类型：

| 类别 | 维度 | 方向 |
| --- | --- | --- |
| 终局 | 终局概率、对手最坏值、对手回应覆盖率 | 最大化 |
| 时间 | 距终局回合数、激活数 | 最小化 |
| 资源 | 终局资源余量、己方实际花费 | 余量最大、花费最小 |
| 交换 | 模型分交换、场景分变化、场景压力 | 最大化 |
| 空间 | 射程/移动/LOS/站位最小容错 | 最大化 |
| 鲁棒性 | 独立可达路线数 | 最大化 |
| 构筑 | 达成路线所需己方分数、被牵制的对手分数 | 己方最小、对手最大 |
| 未知 | 未展开随机/回应/规则质量 | 最小化但只排序 |
| 计算 | strict 调用、节点和运行时间 | 最小化但只调度/排序 |

较小的必要己方军表投入代表“用更少投入仍能建立同一终局路线”的优势，但只有在终局、状态、对手和扩展上下文相同且有保序证明时，才能参与精确路线支配。不同构筑或不同状态不能仅凭分数低就互相删除。

## 三种淘汰

### 规则硬反证

只有以下证据可标为规则不可能：

- 同一绑定状态和动作的 Host exact reject 或 strict terminal contradiction；
- 精确能力缺失；
- 经过证明的乐观移动、射程、伤害、资源或时间上界仍无法满足义务。

### 提议宇宙下界

概率、对手最坏值、最大时间跨度和可选的必要军表投入上限由运行配置声明。只有候选的乐观上界仍低于最小门槛，或最乐观成本仍超过上限，才停止展开。该路线记作 `proposalExclusion` 并保存遗漏分母/质量；这不是规则反证，也不能支持全局最优声明。

区间跨越门槛时继续保留，并记录 `floorUncertainty`。默认概率下界为 `0`，在固定基准校准前不擅自写入战术阈值。

### 精确 Pareto 支配

只有同时满足以下条件，路线标签才可移入冷存档：

- 相同完整规则状态、终局证明后缀、赢家和搜索模式上下文；
- 两条路线都已有 strict terminal witness；
- 所有硬支配维度均为精确值；
- 每个硬维度都有“共享前驱扩展下保序”的证明；
- 被支配路线不携带必须独立累计的 Chance 概率贡献；
- 一条路线在所有硬维度不差并至少一项严格更好。

被支配标签仍保留 provenance，不物理抹除。未搜索质量、strict 调用数、节点数、运行时间、即时模型/场景交换、空间容错和路线冗余都不参与硬支配。

## 两种模式

### 当回合模式

- `turnDistance=0` 是硬时间范围。
- 目标是穷尽终局相关合法动作、对手回应、Chance 质量和触发/反应闭包。
- strict 路线可以先报告，但只有上述游标全部闭合才可成为 exact promotion。
- 适合本回合刺杀、当前结算和微型精确比较。

### 长线模式

- 胜利相对时间迭代加深；第一版校准默认最多四个友方回合，可由显式配置改写。
- 允许资源准备、主动兑换、暂时材料或场景亏损和完整对手回合。
- 只要具体终局路线 strict 可执行，就可作为“最佳已发现候选”报告；对手、Chance 或规则闭包未穷尽时不能升级为 exact strategy proof。
- 预算停止和主观门槛遗漏都进入 unresolved/提议分母。

## 排序而非规则

稳定偏好顺序优先 strict 路线、终局概率下界、对手最坏值、较少未知、较短时间、场景/材料交换、空间容错、冗余和计算成本。这个顺序只决定先展开或先展示什么，不是奖励真值，不进入 rules-v1 状态，也不能直接作为 MuZero 环境回报。

即时掉分、材料亏损、主动兑换、路线较长、人工战术先验和 LLM/Skill 偏好永远不能单独证明路线无效。它们只有在最终终局义务、明确时间上界或 exact Host 转移失败时才会间接导致淘汰。
