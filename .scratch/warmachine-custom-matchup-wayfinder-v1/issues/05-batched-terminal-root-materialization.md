# 批量物化刺杀与得分需求组终局根

Type: prototype
Status: open
Blocked by: 02, 03, 04
Part of: ../map.md

## Question

怎样按构筑宏型和详细需求组分批生成真实军表终局根，覆盖不同轮次、位置、干扰、资源、生命、缺员、胜利动作和 Steamroller 得分来源，同时维持有限预算和完整处置分母？

## Acceptance

- 刺杀与得分分别调度，覆盖任务时域内全部详细需求组和所有构筑宏型。
- 每个组有限展开军表、执行者、目标、资源、生命、损失、位置、地形、控制/争夺和动作类别；等价合并需要行为签名证据。
- 输出区分 strict 根、Host 拒绝、候选过滤、输入错误、规则未知和预算延迟，并守恒代表质量。
- 任务专属根绑定真实双方军表和卡牌模型；通用能力 pin 不能计入任务路径完成数。
- 批任务支持分片、并行、断点恢复、异常租约接管和 Host 收据失效。

- `64/64` 个任务均已绑定严格合法开局，归并为 `39` 个真实军表/场景/地图/部署/先手开局，覆盖全部七个 Steamroller 场景和三类场景地形设置。开局只证明合法部署，不证明后续终局或反向路径。
- 修复了两项会污染后续执行的身份错误：部署区现在按 Attacker/Defender 而非固定玩家编号定向；终局批次开局键现在包含场景与场景地形，不再用仅描述构筑/阵型的旧 `openingKey` 在不同场景间碰撞。旧构筑键仍作为来源保留。
