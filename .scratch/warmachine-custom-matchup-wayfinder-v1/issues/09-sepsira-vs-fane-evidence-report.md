# 产出 Sepsira 六队 Swarm 对 Fane 的可论证报告

Type: prototype
Status: open
Blocked by: 05, 08
Part of: ../map.md

## Question

怎样在四名 Fane 领袖、不同合法军表、地图、部署和先后手下，对固定 Cryx 核心给出可复盘的优劣结论、构筑建议和操作路线，同时严格区分已证明值、区间、筛选指标与覆盖不足？

## Acceptance

- 四名 Fane 领袖各有目标驱动合法军表候选、精确配装、地图/部署格和刺杀/得分路线证据。
- 报告展示每个初始状态的精确值或区间、已发现分支、概率、对手回应、资源/交换/位置变化和未闭合质量。
- 比较杀伤、控场、得分、反击后状态和长线续航，不只比较一次击杀或静态面板。
- 给出中文构筑与操作指导，所有结论可点击回到 strict 路线或明确标记为筛选假设。
- 不宣称代表池之外的全局/阵营最优，也不把旧历史实验当当前 Host 证据。
