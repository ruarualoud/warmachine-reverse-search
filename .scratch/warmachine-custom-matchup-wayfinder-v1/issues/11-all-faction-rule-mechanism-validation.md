# 验证全阵营独有机制可被搜索调用

Type: task
Status: open
Blocked by: 04, 05, 08, 10, 20, 21
Part of: ../map.md

## Question

怎样证明搜索器不是只适用于 Cryx/Fane 普通攻击，而能通过 Host 正确调用所有阵营在构筑、部署、资源、移动、攻击、反应、生命周期和场景上的独有规则？

## Acceptance

- 建立规则原子/钩子到搜索动作、终局需求和 strict 场景证据的完整可调用矩阵。
- 至少包含 corpse/soul/hunger、focus/fury/frenzy、Gravediggers 空投/预备队、多模型单位、可配装战兽/战甲、反应、替换/RFP 和场景专属机制。
- 每个纳入完成口径的特殊规则都有真实卡牌、真实状态、合法动作枚举、strict 执行和正反场景；只做静态文本识别不算覆盖。
- 任一未映射、来源漂移或关联闭包缺口会 fail-closed，并列出受影响阵营、军表、终局组和路径。
- 用至少三个机制结构显著不同的阵营完成跨军表端到端搜索，不以单个微夹具代替路径可调用性。
