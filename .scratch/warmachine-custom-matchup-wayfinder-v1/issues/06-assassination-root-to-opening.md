# 将真实刺杀终局根反推到合法开局

Type: prototype
Status: open
Blocked by: 02, 04
Part of: ../map.md

## Question

怎样把首个任务专属刺杀终局根接入既有多回合反向前沿，恢复动作、激活顺序、移动路径、底盘碰撞、资源、Chance、反应和历史损失，最终与一个合法部署初始状态汇合并独立严格正向重放？

## Acceptance

- 反推从后续回合终局坐标开始，不把部署坐标替代终局假设。
- 每个前驱动作通过现有原子/钩子义务生成，并由 Host strict 正向执行验证；未知逆算保持 unresolved。
- 移动路线、激活先后、单位编队、模型碰撞、Fury/Focus、Frenzy、击杀生命周期和可选触发完整保留。
- 至少一条真实 Cryx/Fane 刺杀路线连接到合法部署，并在不读取旧回执作为执行输入的情况下独立重放到同一终局。
- 其它未展开位置、随机结果、对手选择和路线质量继续留在上界。
